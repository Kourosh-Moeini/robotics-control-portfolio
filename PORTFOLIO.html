03

External-magnet control: 10 Hz policy

Trained a DDPG-based catheter-tip controller in Python/PyTorch while a MATLAB Cosserat model simulated the catheter and the effect of an external magnet.

My contribution. I built the learning and evaluation workflow, linked Python and MATLAB, and tested target reaching and trajectory tracking before experimental transfer.

Selected exactly from Main Code-500 eps-10 HZ.ipynb, not the 100 Hz alternative.

Source selection and scope

The historical project is called “2 DOF”, referring to the evaluated tip-tracking task; the saved implementation has a nine-component observation and three external-magnet position commands with fixed magnet orientation. MATLAB mechanics runs at 100 Hz and the policy holds each action for ten steps (10 Hz control). The critic in this archived implementation fits immediate rewards; the source is preserved rather than silently converted to a different DDPG algorithm. The 50 MB sampling dataset, weights and full workspaces are omitted.

05

Five-DOF tip control with an external magnet

Extended the learned controller to tip position and direction tracking using external-magnet translation and rotation.

My contribution. I developed and evaluated the Python/PyTorch policy linked to the MATLAB magnetic-catheter model and selected the final 2,000-episode experiment.

Selected exactly from Main Code-2000 eps-min v w-Rand-cube-13.ipynb, as specified by me.

Source selection and scope

Five task DOFs mean three position coordinates plus two independent direction coordinates. The source has 19 observation values and six actions (three linear and three angular magnet-motion commands); it does not independently control catheter roll. This quasi-static environment uses dt=1.0, so the 10 Hz claim from the separate position-control project is not applied here. This archive also uses immediate-reward critic targets. The 70 MB sampling dataset, weights and workspaces are omitted.

Benchmarking agentic control and system identification

Defined dynamic-system examples and control tasks, ran experiments, and evaluated agent/model performance for team-provided MPC, adaptive-control and system-identification modules.

My contribution. My contribution is the benchmark cases, experiment setup, testing, metrics, comparisons and reporting. The team supplied the core controller/identification modules; I do not claim sole authorship of those systems.

Includes selected personal testing/reporting code from a public training repository, with saved MPC, adaptive-control and system-identification figures. The public training suite uses mocked agents and is distinct from the real-model experiments.

Source selection and scope

Core company/team agent implementations, prompts, API keys and private datasets are not included. The local driver reference and the team's private core are excluded from this public repository. Plot labels alone do not prove successful LLM calls: fallback runs must be distinguished using the run manifests. Derivative-validation MSE and state-trajectory verification MSE are different metrics; cross-system raw errors have different physical units. No new ranking or acceptance-rate claim is inferred here.

SOFA magnetic-catheter simulation

Built and explored soft-catheter simulations in SOFA, including a beam model coupled to the changing wrench from an external magnet.

My contribution. My work includes the catheter/magnet simulation workflow, configuration, trajectory inputs, evaluation plots and rendered examples. I am also familiar with MuJoCo.

A compact dynamic-magnet example is supplied with its Python helpers, one original result plot and two existing simulation videos.

Source selection and scope

The SOFA example requires a compatible SOFA runtime, SofaPython3 and BeamAdapter; it is not a pure-Python pip-only application. SOFA_ROOT is configured by the reviewer rather than hard-coded to my workstation. MuJoCo familiarity is stated separately; no MuJoCo project is claimed or fabricated. The videos show previously saved simulation results.
