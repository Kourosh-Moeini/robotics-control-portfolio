# SOFA magnetic-catheter simulation

Built and explored soft-catheter simulations in SOFA, including a beam model coupled to the changing wrench from an external magnet.

## My contribution

My work includes the catheter/magnet simulation workflow, configuration, trajectory inputs, evaluation plots and rendered examples. I am also familiar with MuJoCo.

## Selection and status

A compact dynamic-magnet example is supplied with its Python helpers, one original result plot and two existing simulation videos.

## Scope of this sample

The SOFA example requires a compatible SOFA runtime, SofaPython3 and BeamAdapter; it is not a pure-Python pip-only application. SOFA_ROOT is configured by the reviewer rather than hard-coded to my workstation. MuJoCo familiarity is stated separately; no MuJoCo project is claimed or fabricated. Saved videos are historical outputs, not a claim that this copy has been re-simulated.

Open `media` for the existing figures/videos and `code` for selected source. The portfolio-wide `SOURCE_MANIFEST.json` records file hashes and extraction details. Full original research folders remain separate.
